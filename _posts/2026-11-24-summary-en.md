### [GLM-5.4 开放 Coding Plan](https://x.com/ZixuanLi_/status/2124719275864670681) ⭐️ 5.0/10

智谱（Z.ai）方面人士 Zixuan Li 在 X 上发布公告称，GLM-5.4 已向所有 GLM Coding Plan 用户开放，新增视觉能力，编程表现进一步增强；按周计配额的套餐中，GLM-5.4 的配额比 GLM-5.3 提高 50%。这是一条套餐与模型能力更新公告，不是新产品发布，公开材料未披露具体定价、用户量或收入数据。

telegram · zaihuapd · Nov 23, 04:47

**「Why now」** The change that matters right now is packaging, not raw capability: GLM-5.4 is available only inside the GLM Coding Plan subscription, and weekly-quota plans get 1.5× the GLM-5.3 quota, per Z.AI&\#x27;s own docs. A third-party write-up states it is not yet on a pay-as-you-go API and the public API price page still lists GLM-5.3 as newest, so anyone building on it today is tied to a subscription seat rather than metered API access. That makes the current window one for tools that sit on top of a coding subscription \(or for prototyping cheaply\), not for products that need per-token API economics; how long the subscription-only phase lasts is not disclosed in the available material.

**「能不能做成产品」** 这条本身不是可做的产品，而是可以压低你自建产品模型成本的一项输入：如果你做的是面向个人开发者的 AI 编程辅助工具（如代码审查、仓库问答、截图转代码），GLM-5.4 新增的视觉能力和更高的周配额意味着同样的订阅预算能跑更多请求，MVP 可以围绕“截图/设计稿 → 代码”或“PR 自动审查”做，两三人一两周能出原型，收费走订阅或按量。但卡点在于：你卖的是套壳能力，模型方随时可以自己推出同类官方工具，且公开材料没有给出 API 单价，成本模型无法核算，需要自己去查实际计费。

**「能不能接单」** 有间接的服务需求迹象但不强：可以给已经买了 Coding Plan 的小团队做“把 GLM-5.4 接进现有 IDE / CI 流程”的部署与培训，交付物是配置、内部提示词模板和一次培训。但材料里没有任何客户询价、招聘或社群提问作为需求证据，这条需求目前只能算推测，不建议作为主要接单方向。

**「Money side」** The only concrete commercial fact available is the vendor&\#x27;s own pricing page: GLM Coding Plan plans start at $18/month and cover GLM-5.4, GLM-5.3, GLM-5.3-Flash and other models for use in Claude Code, Cline, Kilo Code and similar tools \(tool-2-3\). That is an official list price, not evidence of paying customers, revenue or retention. The announcement itself gives no revenue, customer-count or procurement data, and no independent source in the supplied material reports any. Whether the 50% weekly-quota increase for GLM-5.4 reflects real demand or a competitive response is not disclosed.

**「风险」** 最直接的风险是模型方自己下场做终端产品，把套壳工具的生存空间挤掉；其次是配额与价格政策由厂商单方面调整（本次配额提升 50% 本身就是厂商行为，也可能反向收紧），依赖单一模型供应商的产品议价能力很弱。
